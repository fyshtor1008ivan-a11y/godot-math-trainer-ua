# Math Trainer UA

Повний 2D-математичний тренажер для Godot Engine 4.

Як запустити:
1. Відкрийте цей каталог в Godot 4.
2. Дочекайтесь, поки проект завантажиться.
3. Натисніть кнопку Play.

Що містить проект:
- головне меню з вибором режиму та складності;
- 30-секундний раунд-таймер;
- комбо, очки, 3 життя;
- режимы: додавання, віднімання, множення, ділення, мікс;
- сцену програшу з результатами;
- візуальні ефекти через Tween, частинки та screen shake;
- інтерфейс українською мовою.

Підтримувана версія Godot: 4.x
